# 鸭狼 · 新华动物园奇异兽类展区 XHZ-2019-073

一个一本正经胡说八道的恶搞物种展板网站：把一幅手绘涂鸦包装成动物园正式展板，
介绍所谓「鸭狼（李氏鸭狼）」——生活在天津海河流域、最早由李氏发现、目前在新华动物园仅存一只的保护动物。

## 页面内容

- 展板标题区：又称「李氏鸭狼」、学名 `Anas lupus lii`、基本档案表（分类地位、保护级别、现存数量、分布）
- 三个栏目（文字刻意从简）：物种简介 / 分类争议（可否归入犬科存争议）/ 名称由来（故名「李氏鸭狼」）
- 互动区「互动观察装置」：按下按钮播放 5 帧、0.9 秒的「跳起来咬人」动作分解
- 页脚：观赏守则、虚构声明

## 重新生成动画帧

`tools/generate-frames.ps1` 用 GDI+ 把照片里的铅笔线条抠成透明 PNG：
先用大半径均值模糊求局部底色，再用「底色 − 亮度」得到线条强度并转成 alpha，
最后按帧参数（缩放、旋转、位移、速度线）合成 900×800 的透明画布。

```powershell
pwsh -NoProfile -ExecutionPolicy Bypass -File tools/generate-frames.ps1
```
